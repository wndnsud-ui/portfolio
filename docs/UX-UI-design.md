# DecisionFlow UX/UI 설계

## 방향

첨부 시안의 두 번째 대시보드를 기본 구조로 삼는다. 흰 바탕과 보라·파랑 포인트, 옅은 배경의 상태 카드, 둥근 패널을 공통으로 사용한다. 세 번째 시안의 회의 등록 → 전사 → 요약 → 결정 검토 → 업무 확정 흐름을 기존 기능에 연결한다.

## 화면 구조

| 화면 | 주요 콘텐츠 | 주요 행동 |
| --- | --- | --- |
| 홈 | 인사, 홈 검색, 상태 지표, 최근 회의, 업무, 프로젝트 현황, 최근 결정 | 회의 시작, 항목 상세 열기 |
| 회의 | 검색, 프로젝트 필터, 회의록 목록 | 등록·녹음·업로드, 결정 후보 검토, 화자별 업무 분석, Notion 전송 |
| 프로젝트 | 프로젝트 목록과 상세 | 프로젝트 생성, 회의 원문·요약·연결된 결정과 업무 확인 |
| 업무 관리 | 프로젝트·상태·담당자·위험도·기한 필터 | 업무 생성·수정, 담당자·기한 지정 |
| 결정사항 | 프로젝트별 결정 카드 | 초안 검토, 결정 확정·수정 |
| 설정 · 연동 | 기존 계정과 외부 서비스 설정 | 연동 정보 설정 |

데스크톱은 왼쪽 고정 메뉴와 상단 액션, 두 열의 홈 패널을 사용한다. 1150px 이하에서는 홈 패널을 한 열로 전환한다. 900px 이하에서는 상단 브랜드와 하단 홈·프로젝트·새 회의·업무·더보기 메뉴를 사용한다. 더보기에서 회의·결정사항·설정까지 접근한다. 480px 이하에서는 프로젝트 카드도 한 열로 표시한다.

## 홈 데이터 기준

- 진행 중 업무: 완료와 취소를 제외한 전체 업무. 실제 `in_progress` 상태만을 뜻하지 않는 미완료 지표다.
- 오늘 마감: 서울 날짜 기준 오늘이 마감일인 미완료 업무.
- 이번 주 회의: 서울 날짜 기준 월요일부터 일요일까지의 등록된 회의.
- 검토 대기 결정: `draft` 상태의 결정. 승인 기능을 별도로 가정하지 않는다.
- 내 업무: 로그인 사용자 표시 이름과 담당자가 일치하는 업무. 일치 항목이 없으면 제목을 ‘팀 업무’로 바꾸고 전체 업무를 보여준다. 정확한 개인 업무 분류는 향후 담당자 사용자 ID 연결이 필요하다.
- 프로젝트 업무 완료율: 취소 제외 업무 중 완료 업무 비율. 업무가 없으면 0%로 표시한다.
- 홈 검색: 로드된 프로젝트명·회의 제목·업무명·결정 제목에 적용한다. 회의 화면의 기존 원문 검색과 구분한다.
- 최근 회의와 결정은 날짜 내림차순, 업무는 마감일 오름차순으로 표시한다.
- 지표와 전체보기는 해당 목록을 연다. 지표 값에 맞춘 목록 필터 자동 적용은 후속 개선 범위다.

## 회의 UX 흐름

1. 새 회의에서 프로젝트와 회의 정보를 입력하고 기존 녹음·파일 업로드 기능을 사용한다.
2. 전사 결과를 확인·수정하고 회의를 저장한다. 진행률은 실제 전사 기능에서 제공하는 상태만 표시한다.
3. 회의 상세에서 AI 쟁점 요약을 실행하고 결과를 확인한다.
4. 회의 목록의 AI 결정 검토에서 후보와 근거를 검토·수정한 후 확정한다.
5. 화자별 쟁점·업무 분석에서 담당자·기한을 검토하고 업무를 저장한다.
6. 프로젝트 상세와 업무 목록에서 결과를 추적하고 필요할 때 Notion으로 전송한다.

AI 출력은 검토 후보로 제시하며 사용자 확정 전에 실제 결정이나 업무로 간주하지 않는다. 기존 API, 모달, 녹음 및 검토 동작을 유지한다.

## 상태 및 접근성

데이터 없는 상태에는 안내 문구를 표시한다. 로딩과 API 실패는 구분한다. 필터 탭에는 선택 상태를 제공하고, 메뉴와 아이콘 버튼에는 접근성 이름을 붙인다. 색상 외에 상태 문구를 표시하고 키보드 포커스를 제공한다. 업무 행은 상세 이동 버튼이며 완료 체크박스로 표현하지 않는다.

## 후속 범위

팀·워크스페이스 권한, 일정 시간·캘린더, 알림, 기술 블로그, YouTube·문서 변환, 랜딩 페이지는 이번 화면 수정에 포함하지 않는다. 실제 데이터 모델과 API를 확인하고 별도 구현한다. 시안의 가상 인물·알림 수·증감 수치·예시 업무는 실제 데이터처럼 표시하지 않는다.

## 확인 기준

TypeScript 검사와 Vite 프로덕션 빌드를 수행한다. 수동 확인은 로그인 후 1440px·768px·390px·320px에서 홈, 메뉴, 새 회의, 프로젝트·회의·업무·결정 상세 이동, 필터와 검색, 빈 데이터, 긴 제목을 대상으로 한다. 실제 녹음과 AI·Notion 호출은 해당 서비스가 연결된 환경에서 확인한다.
