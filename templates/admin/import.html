노션 독서 기록을 사이트로 옮겨요. 노션 → 사이트 한 방향이에요.

파일로 가져오기

노션 독서 DB를 JSON 또는 CSV로 내보낸 파일을 올리면 책과 노트를 넣어요. 같은 노션 페이지는 새로 만들지 않고 고쳐 넣어요. 지금 책장에는 {{ books }}권이 있어요.
